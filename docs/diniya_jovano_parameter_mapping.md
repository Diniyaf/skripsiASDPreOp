# Diniya-Jovano Parameter Mapping Notes

Date: 2026-06-06

This note explains how to interpret Diniya's accepted Zoya pre-closure ASD parameters when handing them to Jovano's post-closure model. It is a mapping guide, not a direct-copy instruction.

## Core Warning

Diniya and Jovano use different model structures:

- Diniya uses a nested parameter struct, for example `params.E.LV.EA`, `params.R.SAR`, `params.asd.Cd`.
- Jovano uses flat parameter names, for example `params.Emax_lv`, `params.R_sa`, `params.R_ASD`.
- Diniya's state vector is not the same as Jovano's state vector.
- Diniya's pre-closure model includes an active ASD shunt. Jovano's Zoya post-closure model is a closed-shunt model.

Therefore, Jovano should not blindly copy Diniya's parameter struct into his model.

## Elastance Mapping

Diniya's elastance equation is:

```matlab
E_ch(t) = EA_ch * e_ch(t) + EB_ch
```

Jovano's elastance equation is:

```matlab
E_ch(t) = Emin_ch + (Emax_ch - Emin_ch) * e_ch(t)
```

Because both formulations use a normalized activation `e_ch(t)` in `[0, 1]`, the mathematical adapter is:

```matlab
Emin_ch = EB_ch
Emax_ch = EA_ch + EB_ch
```

So the correct mapping is:

| Diniya | Jovano | Rule |
|---|---|---|
| `E.LV.EB` | `Emin_lv` | `Emin_lv = E.LV.EB` |
| `E.LV.EA + E.LV.EB` | `Emax_lv` | `Emax_lv = E.LV.EA + E.LV.EB` |
| `E.RV.EB` | `Emin_rv` | `Emin_rv = E.RV.EB` |
| `E.RV.EA + E.RV.EB` | `Emax_rv` | `Emax_rv = E.RV.EA + E.RV.EB` |
| `E.LA.EB` | `Emin_la` | `Emin_la = E.LA.EB` |
| `E.LA.EA + E.LA.EB` | `Emax_la` | `Emax_la = E.LA.EA + E.LA.EB` |
| `E.RA.EB` | `Emin_ra` | `Emin_ra = E.RA.EB` |
| `E.RA.EA + E.RA.EB` | `Emax_ra` | `Emax_ra = E.RA.EA + E.RA.EB` |

Do not map `EA` directly to `Emax`. `EA` is the active amplitude above the passive baseline, not the peak elastance itself.

## ASD Shunt Mapping

Diniya's accepted Zoya pre-closure model uses an open ASD mechanism. In orifice mode, the important pre-closure fields are:

- `params.asd.Cd`
- `params.asd.area_mm2`
- `params.asd.mode`
- `params.R.asd` may be inactive if mode is `orifice_bidirectional`

Jovano's post-closure model uses a linear closed-shunt convention:

```matlab
params.R_ASD = 1e9;  % or Inf-equivalent
```

For post-closure, Jovano should not use Diniya's `asd.Cd` or `asd.area_mm2` as an open shunt. Those fields document the pre-closure defect mechanism only. Closure should be applied in Jovano's own convention.

## Recommended Handoff

Send Jovano the exported package generated by:

```matlab
run('scripts/export_zoya_jovano_handoff.m');
```

The package includes:

- complete `seed_zoya` MAT struct;
- accepted pre-closure metrics;
- Diniya-to-Jovano parameter mapping CSV;
- README explaining what can and cannot be transferred.

## Scientific Interpretation

The best shared workflow is not direct parameter copying. The defensible workflow is:

```text
Diniya accepted pre-closure operating point
-> documented closure transition expectation
-> Jovano independent chronic post-closure model
-> compare shared outputs and physiological trends
```

This is necessary because Zoya's pre-closure and post-closure data are separated by time. The post-closure state may include recovery and remodeling that are not represented by simply setting the ASD resistance to infinity.
