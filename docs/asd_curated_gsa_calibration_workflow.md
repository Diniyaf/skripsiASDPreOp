# ASD Curated GSA and Masked Calibration Workflow

Date: 2026-06-01

This note documents the cleanup that aligns the Patient Zoya ASD workflow with the staged Hafiz-Keisya unified VSD pattern while preserving ASD-specific physiology and Patient Z data availability.

## Why This Cleanup Was Needed

The previous ASD GSA/calibration code already contained most of the required ideas:

- ASD candidate parameter groups A/B/C.
- Target-tier governance.
- Full/curated GSA.
- Staged calibration.
- Baseline vs calibrated output tables.

However, several pieces were not connected cleanly:

- The GSA runner was named `run_zoya_asd_gsa_groupA.m` even though it sampled Groups A+B+C.
- The calibration runner still used a hardcoded active set from an older decision note.
- The 26-row ASD output table did not explicitly label each output as primary target, secondary guard, derived comparison, or model prediction.
- Secondary measured pressures such as SBP, DBP, PAPsys, and PAPdia were not clearly separated from hard primary mean-pressure/flow targets.
- The calibration acceptance logic could accept a candidate that improved Qp/Qs while degrading systemic pressure.

## Updated Workflow

The cleaned workflow is:

```text
healthy baseline
-> pediatric scaling
-> ASD clinical seeding
-> curated ASD parameter library
-> curated ASD GSA
-> active mask from Sobol ST + target tiers
-> staged calibration
-> clinical fit guard + physiological validity gate
-> accepted or rollback candidate
```

This mirrors the unified VSD structure:

```text
initial GSA
-> optimization mask
-> masked calibration
-> validation/final GSA
```

but uses ASD-specific shunt physiology and Patient Zoya target availability.

## Output-Tier Governance

The 26-output panel generated by `src/utils/asd_output_table.m` is now explicitly tiered.

Hard primary calibration targets:

- `QpQs`
- `Qp_Lmin`
- `Qs_Lmin` / `CO_Lmin`
- `SAP_mean` / `MAP`
- `PAP_mean`
- `LAP_mean`

Measured secondary guard targets:

- `SAP_max` / SBP
- `SAP_min` / DBP
- `PAP_max` / PAPsys
- `PAP_min` / PAPdia

Derived comparison / qualitative guard outputs:

- `Q_ASD_Lmin`
- `Q_ASD_mean_mLs`
- `ASD_direction`
- `DeltaP_LA_RA`

Model prediction outputs:

- LV/RV stroke volumes.
- LV/RV EDV and ESV.
- LVEF and RVEF.
- SVR and PVR.
- RAP_mean and RVP_mean.

The model prediction outputs remain important for thesis discussion, but they are not direct fitting targets unless clinical evidence becomes available.

## Curated ASD Parameter Library

The curated library is generated by:

```text
src/calibration/asd_candidate_param_sets.m
src/calibration/build_asd_curated_parameter_library.m
```

Group A: primary vascular and shunt candidates.

- `asd.Cd`
- `R.SAR`
- `R.SC`
- `R.SVEN`
- `C.SAR`
- `R.PAR`
- `R.PCOX`
- `R.PCNO`
- `R.PVEN`
- `C.PAR`

Group B: secondary atrial/preload candidates.

- `E.LA.EA`
- `E.LA.EB`
- `E.RA.EA`
- `E.RA.EB`
- `V0.LA`
- `V0.RA`
- `V0.SVEN`
- `V0.PVEN`
- `C.SVEN`
- `C.PVEN`

Group C: ventricular exploratory/fixed candidates.

- `E.LV.EA`
- `E.LV.EB`
- `E.RV.EA`
- `E.RV.EB`
- `V0.LV`
- `V0.RV`

Group C is monitored by GSA but is not calibrated by default because Patient Zoya pre-closure has no LV/RV volume or EF targets. It can be explicitly enabled only with:

```text
ASD_CALIB_ALLOW_GROUPC=1
```

## GSA Runner Naming

The active runner is now:

```text
scripts/run_zoya_asd_gsa_curated.m
```

The old file:

```text
scripts/run_zoya_asd_gsa_groupA.m
```

is retained only as a compatibility wrapper.

The curated runner writes:

```text
results/tables/zoya_asd_gsa_curated_*.xlsx
results/tables/zoya_asd_gsa_curated_*.mat
```

The ASD GSA default warmup is now 40 cycles because Patient Zoya diagnostic runs showed that 10 cycles often failed steady-state checks. This differs from the VSD GSA default of 10 cycles, but is justified by ASD-specific convergence behavior.

The warmup can be overridden for smoke tests:

```text
ASD_GSA_NCYCLES=10, 30, or 40
```

## Active Mask

The active mask is built by:

```text
src/calibration/build_asd_active_mask_from_gsa.m
```

Selection uses:

- Sobol total-order index `ST`.
- Hard primary targets.
- Measured secondary guard targets.
- Active-set cap for identifiability.
- Group C exclusion by default.

This makes the active calibration set traceable to GSA evidence and target-tier governance, rather than hardcoded in the calibration script.

## Calibration Guard

The calibration objective now has:

- hard primary target error,
- secondary measured waveform guard error,
- parameter plausibility penalty,
- boundary penalty,
- physiological validity penalty,
- steady-state failure penalty.

The post-calibration acceptance gate now rejects candidates that improve one target by strongly worsening measured pressure-flow outputs. This prevents accepting a candidate that raises Qp/Qs while collapsing MAP, SBP, or DBP.

## Current Methodological Position

This cleanup does not claim that the model is already calibrated. It prepares the workflow so that the next GSA and calibration run are methodologically defensible:

```text
curated GSA
-> ST-based active mask
-> staged calibration
-> validity/fit gate
-> accepted or rollback candidate
```
